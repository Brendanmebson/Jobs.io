# Jobs.io – Premium Career OS

![Jobs.io Logo](src/assets/radar-white.png)

Jobs.io is a centralized, premium platform designed to streamline your career growth and job application process. It provides a comprehensive suite of tools to manage your professional journey, from tracking applications to visualizing your success with advanced analytics.

## 🚀 Key Features

- **Job Application Tracking**: Keep a pulse on every application. Track status, timeline, and next steps for every role you apply to.
- **Career Analytics**: Gain deep insights into your job search performance. Visualize application trends, success rates, and volume with dynamic charts powered by Recharts.
- **Document Management**: A centralized hub for your professional documents. Easily manage and access your CVs, resumes, and cover letters.
- **Interview Calendar**: Never miss an opportunity. Integrated calendar for scheduling and tracking interviews, follow-ups, and key career events.
- **Premium User Experience**: A sleek, modern dashboard designed for productivity, featuring both light and dark mode compatibility.
- **Mobile Optimized**: Fully responsive interface that works beautifully on desktops, tablets, and mobile devices.

## 🛠️ Tech Stack

- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **UI Library**: [Material UI (MUI)](https://mui.com/)
- **Iconography**: [Lucide React](https://lucide.dev/)
- **Data Visualization**: [Recharts](https://recharts.org/)
- **Utilities**: [date-fns](https://date-fns.org/)
- **Styling**: [Emotion](https://emotion.sh/)

## 🏁 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/jobs-io.git
    cd jobs-io
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Run the development server**:
    ```bash
    npm run dev
    ```

4.  **Build for production**:
    ```bash
    npm run build
    ```
